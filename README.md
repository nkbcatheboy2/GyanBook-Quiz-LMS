# 📘 GyanBook - The Ultimate Quiz & Learning Platform

GyanBook is a comprehensive, responsive, and dynamic Learning Management System (LMS) built with raw **PHP & MySQL**. It allows users to register, read motivational stories, select specific subjects, take quizzes, and earn printable certificates. 

It also features a powerful **Secure Admin Dashboard** for effortless content management, including bulk uploading questions via Excel (CSV) files.

---

## ✨ Key Features

### 🎓 For Users (Students)
* **Secure Authentication:** User Registration and Login system using encrypted passwords (`password_hash`).
* **Motivational Stories:** A dynamic feed of inspirational stories with a beautiful "Read More" popup (modal) UI.
* **Subject Categories:** Users can choose specific categories to test their knowledge (e.g., General Knowledge, Ramayan, Math, Science).
* **Interactive Quiz Engine:** Fetches random questions from the selected category.
* **Automated Certificates:** Instantly generates a printable, stylish Certificate of Excellence upon exam submission.

### ⚙️ For Administrators
* **Secure Command Center:** Password-protected admin dashboard.
* **Bulk Question Upload (CSV):** Easily upload 100s of questions at once using an Excel/CSV template.
* **Content Management:** Add, Edit, and Delete questions and options seamlessly.
* **Story Management:** Publish and delete motivational stories directly from the dashboard.
* **Performance Tracking:** View a complete log of registered users and their quiz results in real-time.

---

## 🛠️ Tech Stack Used
* **Frontend:** HTML5, CSS3 (Custom Glassmorphism UI, Google Fonts - Poppins), JavaScript (DOM manipulation for Modals)
* **Backend:** Core PHP (Session Management, Password Hashing)
* **Database:** MySQLi (Relational Database)
* **Environment:** XAMPP / Apache Localhost
